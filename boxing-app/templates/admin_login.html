Einmalige Einrichtung

Der Admin-Bereich ist deaktiviert, bis du lokal ein Passwort und einen geheimen Sitzungsschlüssel festlegst.

Erstelle in boxing-app die Datei .env (sie wird nicht auf GitHub hochgeladen) mit:

FIGHTBASE_ADMIN_PASSWORD=DEIN_LANGES_SICHERES_PASSWORT
FIGHTBASE_SECRET_KEY=HIER_EIN_ZUFAELLIGER_GEHEIMER_SCHLUESSEL

Erzeuge den geheimen Schlüssel im VS-Code-Terminal mit python -c "import secrets; print(secrets.token_urlsafe(40))" und kopiere das Ergebnis hinter FIGHTBASE_SECRET_KEY=. Verwende ein selbst gewähltes Passwort mit mindestens zehn Zeichen.

Starte danach python app.py neu und öffne /admin.
